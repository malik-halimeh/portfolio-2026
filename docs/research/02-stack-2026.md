# Research 02 — Frontend toolchain state of the art, 11 October 2026

Compiled by a research agent; version numbers verified against the npm registry on 2026-10-11, dates/features from official blogs and docs. The agent's own recommendation (Astro on Cloudflare) is at the end; the project decision (Next.js on Vercel) and why is in `HANDOFF.md` D-02/D-07.

## 1. Frameworks

| Framework | Latest stable | Published | Notes |
|---|---|---|---|
| Next.js | 16.4.0 | 2026-10-06 ([blog](https://nextjs.org/blog/next-16-4)) | 15.x security support ends 2026-10-21 |
| React | 19.3.0 | 2026-09-09 | `<ViewTransition>` + `addTransitionType` stable; `<Activity>` with RSC support; Fragment refs |
| Astro | 7.3.8 | 2026-10-08 | Astro 7.0 released 2026-06-22; Rust `.astro` compiler; Vite 8/Rolldown |
| Vite | 8.3.4 | 2026-10-08 | Rolldown-only bundler since 8.0 (2026-03-12) |
| React Router | 8.4.0 | 2026-09-15 | Remix v2 and RR v6 EOL June 2026 |
| SvelteKit | 3.0.1 | 2026-10-06 | needs Node 22+ |

**Next.js 16.4 specifics:** Turbopack is the only bundler. Cache Components (`'use cache'` + `cacheLife` + Partial Prefetching) are the recommended model and on by default in `create-next-app`; PPR absorbed into it. New `ensureStatic = 'navigation' | 'prefetch' | 'shell'` route/layout export fails the build if anything dynamic sneaks in (ideal for a portfolio). `reactCompiler: true` stable; Rust React Compiler experimental. Stable Adapter API since 16.2 (Vercel, Bun verified; OpenNext for Cloudflare/Netlify/AWS "in active development"). `output: 'export'` still cannot use the default `next/image` loader, ISR, redirects/headers, Server Actions or Proxy. Next.js 16.4 is currently broken on OpenNext/Cloudflare (issue [#1355](https://github.com/opennextjs/opennextjs-cloudflare/issues/1355)); so Next means Vercel. Security: Node-runtime `next/og` `ImageResponse` RCE via attacker-controlled SVG fixed in 16.3.6 (GHSA-vcvr-r3jv-pc5j); Edge runtime unaffected; never pass user-controlled SVG to OG.

**Astro 7 specifics:** zero JS by default, Server Islands stable since 5.0, Fonts API still experimental, native cross-document view transitions preferred. Cloudflare acquired the Astro team (2026-01-16) and VoidZero/Vite (2026-06-05); both stay MIT.

## 2. Styling

**Tailwind CSS 4.3.3** (4.3.0 on 2026-05-08, [blog](https://tailwindcss.com/blog/tailwindcss-v4-3)). CSS-first: `@import "tailwindcss"; @theme { ... }`, no config file, Lightning CSS/Oxide engine, `@tailwindcss/postcss` or `@tailwindcss/vite`. 4.2 added logical-property utilities (`inset-s-*`/`inset-e-*`; `start-*`/`end-*` deprecated) which matter for RTL, and `font-features-*`. 4.3 added scrollbar utilities, `@container-size`, stacked `@variant hover:focus`, `--default()` for custom utilities. Container queries built in since 4.0.

**Browser support (caniuse, 2026-10-11, global):** `:has()` 95.9%; `@property` 96.1%; container queries 95.9%; `oklch()` 95.1%; `color-mix()` 94.8%; `text-wrap: balance` 93.6%; `@starting-style` 93.1%; same-document View Transitions 92.9%; `light-dark()` 91.3%; cross-document `@view-transition` 87.9% (no Firefox); scroll-driven animations 87.8% (Firefox 160+ just shipped); anchor positioning 87.4% partial-heavy; `field-sizing` 87.2%; `text-wrap: pretty` ~87%. Read: anything above ~91% is safe unguarded; the rest are progressive enhancements.

## 4. Typography

Google Fonts: 1,942 families / 553 variable (Aug 2026). **Overused in 2026:** Inter, Geist, Space Grotesk, Manrope, DM Sans, Outfit, Plus Jakarta Sans (the clean neo-grotesk family reads as template); Bricolage Grotesque ("most-installed new sans of the last 24 months") and Instrument Serif are on the same trajectory; Satoshi saturated on personal sites. **Distinctive, fresh, free, variable:** Fraunces, Newsreader, Funnel Display + Funnel Sans (NORD ID), Host Grotesk, Schibsted Grotesk, Hanken Grotesk, Onest, Young Serif, Gloock, Cormorant, Syne/Unbounded. Mono: Geist Mono, JetBrains Mono, Commit Mono, IBM Plex Mono. Recipe: one expressive display face + one quiet text sans, at most two variable files. (Project choice: Archivo variable with width axis, see HANDOFF D-04.)

**Arabic:** IBM Plex Sans Arabic ↔ IBM Plex Sans most balanced professional pairing ([guide](https://maroondm.com/guides/arabic-web-fonts/)); Readex Pro (variable, geometric, UI/headlines); Noto Kufi Arabic (headlines) + Noto Naskh Arabic (long-form); Vazirmatn (excellent text face); Cairo, Tajawal common UI fonts; Rubik covers both scripts. Rules: Arabic at weight 500 looks heavier than Latin 500, tune per script; `unicode-range` subsets so Arabic loads only on `/ar`; Tailwind logical utilities; `dir="rtl"` on `<html>`.

## 6. Forms, analytics, OG, SEO

- No-backend forms: Web3Forms free 250/mo; Formspree free 50/mo; Resend free 3,000/mo (100/day) called from a route handler; Cloudflare Turnstile free for spam. (Project decision: no form.)
- Analytics: Umami Cloud Hobby free 100k events/mo; Plausible from $9/mo; Vercel Web Analytics 50k events/mo on Hobby (`@vercel/analytics` 2.0.1); Cloudflare Web Analytics free on a Cloudflare zone.
- OG images: `@vercel/og` 1.0.3 / satori 0.47.1 (2-20x faster since March 2026). Use the Edge runtime for `ImageResponse`.
- SEO: `app/sitemap.ts` + `robots.ts`; Lighthouse 13.3+ has an "Agentic Browsing" category auditing llms.txt and WebMCP, but llms.txt adoption is 5.6-8.7% and Google says AI Overviews ignore it: ship a small one, do not invest further. JSON-LD `Person` + `WebSite`, hreflang en/ar, `<meta name="theme-color">` with `light-dark()` are the 2026 baseline.

## 7. Accessibility and performance norms

- Targets: LCP ≤ 2.5 s, INP ≤ 200 ms, CLS ≤ 0.1 at p75. Lighthouse 13.5.0 (2026-09-18). Lab score is TBT-driven; 100 does not guarantee field INP.
- Reduced motion: Motion `<MotionConfig reducedMotion="user">` + `useReducedMotion()`; GSAP `gsap.matchMedia()`; CSS `@media (prefers-reduced-motion)`; never instantiate smooth scroll under reduced motion.
- Fonts: self-host 1-2 variable WOFF2, `font-display: swap` (or `optional` for zero-CLS first visit), metric-matched fallbacks (`next/font` generates `size-adjust`/`ascent-override` automatically); preload only above-the-fold faces; `unicode-range` split for Arabic.
- Images: AVIF at 96.4% support; `next/image` with explicit sizes; explicit `aspect-ratio` on canvases.
- Lighthouse-100 recipe for animation-heavy sites: keep heavy libs out of the initial bundle (dynamic import, in-view start), animate only transform/opacity, defer analytics to `requestIdleCallback`, split long tasks under 50 ms, use CSS scroll-driven animations for simple reveals.
