# malik-halimeh-portfolio

Personal site of Malik Halimeh, full-stack developer in Saida, Lebanon.

- **Agents and collaborators:** read `HANDOFF.md` first. It holds the design direction, the section-by-section spec, the research, and the progress checklist.
- **Facts:** every number and claim on the site comes from `docs/CONTENT_FACTS.md`.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000 (Arabic at /ar).

## Check

```bash
npm run lint && npm run typecheck && npm run build
```

## Stack

Next.js 16 (App Router, Cache Components, Turbopack), React 19, Tailwind CSS 4, Motion, next-intl, cmdk, Phosphor icons. Deployed on Vercel.
